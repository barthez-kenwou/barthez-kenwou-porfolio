# 💼 Experience Entity

The `Experience` entity tracks professional background and career progression.

## Attributes

- `company`: Name of the organization.
- `role`: Job title.
- `location`: Physical or remote.
- `period`: Start and End dates.
- `description`: Bullet points of achievements and responsibilities.
- `technologies`: Key tools used in this role.

## Folders

- Data: `src/entities/Experience/data/`
- Types: `src/entities/Experience/model/`
