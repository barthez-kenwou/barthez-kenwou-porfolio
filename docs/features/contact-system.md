# 📧 Contact System

This feature facilitates communication between visitors and the portfolio owner.

## Capabilities

1. **Form Handling**: Validation and submission using `react-hook-form` and `zod`.
2. **Direct Contact**: WhatsApp and LinkedIn integrations.
3. **Feedback**: Success/Error notifications for submissions.

## Implementation Detail

- Location: `src/features/ContactForm/`
- Interactions: Uses a dedicated service for email delivery or API submission.
